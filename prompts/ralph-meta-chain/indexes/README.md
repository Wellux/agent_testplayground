# indexes/ — Authoring source for vault-side catalogs

Six index templates per master spec. Each is the **authoring source**
for a corresponding catalog that lives in the user's vault. The
on-disk vault file is regenerated by cron prompts or shims; this file
is the reference for what shape the vault file takes.

## Why "indexes" live in the repo

Two reasons:

1. **Schema authority.** The shape of `90-Meta/index.md` should be
   determined by something the user can review and edit, not buried
   in a prompt. These files are that authority.
2. **Onboarding.** A fresh vault gets seeded with a real index from
   `install.sh seed_one()`, not an empty file.

When the cron prompts regenerate the vault-side catalog, they conform
to the shape documented here.
