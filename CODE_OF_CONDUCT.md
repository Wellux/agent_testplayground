# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The full text is canonical; please read it at the link above.

## Reporting

To report a concern, open a private security advisory at
<https://github.com/Wellux/agent_testplayground/security/advisories/new>
or contact the maintainer via the repo profile. All reports are handled
confidentially.

## Scope

This Code of Conduct applies to all project spaces — the GitHub repo
(issues, PRs, discussions, code review), and any other space where
contributors interact about the project.

Maintainers are responsible for clarifying and enforcing the standards
described in the Covenant, and may take any action they deem
appropriate, including warnings, removal of contributions, or removal
of contributors.
